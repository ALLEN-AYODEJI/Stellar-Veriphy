# Video Tutorials

This folder contains the written transcripts and recording scripts for the
project's tutorial videos.

These are intended to be the source material for the YouTube uploads requested
in issue #386. The repo can store and link the transcripts; the actual video
capture and upload step still happens outside Git.

## Tutorials

| Tutorial | Length target | File |
| --- | --- | --- |
| Getting started | 5-10 min | [getting-started.md](getting-started.md) |
| Verification workflow | 10 min | [verification-workflow.md](verification-workflow.md) |
| Developer setup | 15 min | [developer-setup.md](developer-setup.md) |

## Publishing checklist

1. Record the screen capture using the transcript as the narration script.
2. Export the final video with captions or upload the transcript as subtitles.
3. Publish the video to YouTube.
4. Replace the placeholder links in the main README with the public URLs.
