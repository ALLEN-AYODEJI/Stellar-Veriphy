Installation

Add the widget script to your HTML before the closing body tag:

<!-- 1. Add widget elements -->
<div data-sv-cert-id="YOUR_CERT_ID" data-sv-style="standard"></div>

<!-- 2. Load the widget script -->
<script src="https://cdn.stellarveriphy.com/widget.js"></script>

<!-- 3. Initialize widgets -->
<script>
  StellarVeriphyWidget.init();
</script>
