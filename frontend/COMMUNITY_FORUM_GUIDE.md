# Community Forum Guide

This guide explains how to use and manage the Stellar-Veriphy community forum.

## Overview

The community forum provides:
- Discussion categories for different topics
- User accounts and profiles
- Moderation tools
- Search functionality
- Email notifications
- GitHub integration

## Forum Structure

### Categories

The forum is organized into categories:

- **General Discussion** - General topics and off-topic discussions
- **Help & Support** - Get help with verification and technical issues
- **Tutorials & Guides** - Share and discuss tutorials and guides
- **Announcements** - Official announcements and updates
- **Feature Requests** - Suggest and discuss new features
- **Showcase** - Show off your verified content and projects

## Creating an Account

1. Click "Sign Up" on the community page
2. Provide your email address
3. Choose a username
4. Verify your email
5. Complete your profile

## Starting a Discussion

1. Click "Start New Discussion" or "Start Discussion" in a category
2. Choose an appropriate category
3. Write a clear, descriptive title
4. Add relevant tags
5. Write your message
6. Click "Post"

### Tips for Good Discussions

- **Be Clear**: Write a clear title and detailed description
- **Search First**: Check if similar discussions exist
- **Add Tags**: Use 2-3 relevant tags
- **Include Context**: Provide background information
- **Format Well**: Use proper punctuation and formatting
- **Be Respectful**: Follow community guidelines

## Replying to Discussions

1. Click on a discussion thread
2. Scroll to the reply box
3. Write your response
4. Click "Post Reply"

### Good Practices

- Answer the question asked
- Provide constructive feedback
- Link to relevant resources
- Quote relevant parts of previous replies
- Proofread before posting

## Using Search

1. Use the search bar at the top
2. Search by keywords or phrases
3. Filter by category or tag
4. Sort by relevance or date

## Moderating Content

### For Moderators

- **Edit Posts**: Fix formatting or remove spam
- **Lock Threads**: Prevent further replies
- **Pin Threads**: Keep important discussions visible
- **Move Threads**: Move to correct category
- **Delete Posts**: Remove rule violations
- **Ban Users**: Prevent accounts from posting

### Moderation Tools

Access moderation panel in your admin dashboard to:
- View flagged content
- Manage user accounts
- Review reports
- Update guidelines

## Notifications

### Email Notifications

Subscribe to notifications:
1. Go to User Settings
2. Select "Notifications"
3. Choose categories and types
4. Confirm email address

### Types of Notifications

- New replies to your threads
- Mentions of your username
- New posts in watched categories
- Community announcements
- Moderation actions

## GitHub Integration

### Linking GitHub

1. Go to User Settings
2. Click "Connect GitHub"
3. Authorize the application
4. Your GitHub username will be linked

### GitHub Features

- Link issues to forum discussions
- Reference pull requests in discussions
- Use GitHub OAuth for login
- Share repositories in showcase

- Sharing useful resources
- Following community guidelines

- **New Member** (0-50 points)

1. **Be Helpful**: Try to answer questions and help others

## Moderation Policies

### Warning System

1. **First Violation**: Warning message
2. **Second Violation**: Temporary suspension (1-7 days)
3. **Third Violation**: Extended suspension (1-4 weeks)
4. **Severe Violations**: Permanent ban

### Appeal Process

1. Submit appeal with explanation
2. Moderation team reviews
3. Decision within 7 days
4. Reinstatement or final decision

## Reporting Content

To report inappropriate content:
1. Click "Report" on the post
2. Select reason for report
3. Add optional comment
4. Submit report
5. Moderation team will review

## Frequently Asked Questions

**Q: How do I delete my account?**
A: Go to Settings > Account > Delete Account. Your posts will be anonymized but content remains visible.

**Q: Can I delete my posts?**
A: You can delete your own posts within 24 hours. After that, only moderators can delete.

**Q: How do I recover a deleted account?**
A: Contact support within 30 days. Permanent deletion cannot be reversed after 30 days.

**Q: How are discussions ranked/sorted?**
A: By default, discussions are sorted by latest activity. You can also sort by creation date or popularity.

**Q: Can I mention specific users?**
A: Yes, use @ followed by their username to mention someone.
